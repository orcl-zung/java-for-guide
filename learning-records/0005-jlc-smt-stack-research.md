## 一、官方 JD 证据（jlc.com 诚聘英才页，2022-04 发布，至今在线）

**JAVA开发工程师（深圳福田，招 20 人）**任职要求原文：
1. 本科+，3 年以上经验
2. 熟练 **Spring Cloud 体系**：注册发现、限流熔断、链路追踪，微服务设计与优化经验
3. 精通 **MySQL**
4. 精通 **Nginx、Redis、Memcached、RabbitMQ、Kafka**
5. 设计模式 + 分布式/微服务实战

同页交叉：技术总监（JAVA）要求分布式/微服务、MySQL 调优、缓存/消息/RPC 中间件、Nginx/Tomcat、MQ；高级架构师要求 SpringCloud/Spring/MyBatis、大数据量高并发高可用。→ **嘉立创 Java 栈 = 标准电商级微服务栈，无偏门组件**。

## 二、关键发现：部门分工（决定简历定位）

同页存在独立 **C++ 研发线**：技术总监（C++）职责="制定公司**辅助制造软件**规划"；C++ 工程师="CAM 桌面软件、图形算法、线性代数、电路设计、线路板行业"。

**推论（待锚点确认）**：BOM/坐标解析算法（CAM/工程侧）大概率是 C++ 团队负责，Java 团队做订单域（下单/报价/工单/状态/对接）。→ 简历口径应为"**调度对接解析引擎**"而非"实现解析算法"；被问"算法怎么实现"可答"工程侧 C++ 的解析引擎，我们通过接口/任务队列对接，我负责订单链路"。边界感真实。

## 三、面经证据（牛客 2026-06，社招，福田总部一面 60min）

风格：**极度务实、不深挖源码、筛"基础不牢 + 项目造假 + 只会背八股"**。模块拉分：**MySQL > Redis > Java基础 > 项目细节**。算法只考简单题基本不挂人。

- MySQL（最拉分）：聚簇/二级索引、最左匹配、**索引失效（必考）**、事务隔离、慢SQL全流程（explain/回表/联表/分页）、大表分页联表实战
- Redis：数据结构+场景、**穿透/击穿/雪崩（必背）**、过期删除/内存淘汰
- Java：HashMap、线程池七参数+实际配置、volatile、JVM+GC卡顿排查
- 微服务：Bean生命周期、三级缓存、AOP、Boot自动装配、Nacos/Feign/Gateway
- MQ：解耦/异步/削峰、丢失/重复/**幂等**（面经问 RocketMQ；JD 写 RabbitMQ/Kafka——各部门不统一）
- 项目深挖四连：独立负责模块 / 并发一致性 / 线上bug完整排查 / 优化前后数据对比

**教学对齐**：MySQL 考区 = 第 2 课已覆盖；项目四连问 = reference/0002 应答手册结构。他们明确筛项目造假 → 写真实 SMT 故事策略的外部佐证。
